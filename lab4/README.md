# Лабораторная работа №4 — Реализация электронной цифровой подписи

Программа: `signature.py` (Python 3, стандартная библиотека). Использует модули предыдущих работ: `../lab2/rsa.py` (RSA) и `../lab3/myhash.py` (собственная хэш-функция), поэтому запускать нужно из репозитория:

```bash
python3 lab4/signature.py          # хэш-функция варианта sin (по умолчанию)
python3 lab4/signature.py xor      # или cos, xor — вариант хэш-функции из ЛР3
```

## Схема

```
формирование:  h = H(M);  S = h^d mod n;   передаётся пара (M, S)
проверка:      h' = H(M); h'' = S^e mod n;  подпись верна, если h' = h''
```

Закрытый ключ `{d, n}` есть только у автора — аутентичность и неотказуемость; открытый `{e, n}` — у всех — проверяемость; любое изменение M меняет h' — целостность.

## Особенности реализации

- **Условие h < n.** Хэш из ЛР3 32-битный, а проверка восстанавливает лишь `h mod n`: при n < 2³² подпись не сходится даже на нетронутом сообщении. Поэтому простые p, q берутся из [2¹⁷, 2¹⁸): n = p·q ≥ 2³⁴ > 2³². Пункт меню 7 показывает это на ключах из примера ЛР2 (n = 33).
- **Модификация без пересчёта подписи** — модель злоумышленника в канале: замена, вставка, удаление, перестановка соседних символов, вручную или случайно. При проверке выводится число различающихся бит хэш-сумм.
- **Сообщение** — любой печатный текст ASCII (коды 0..127), включая пустое.
- **Автотест**: 1000 случайных сообщений длины 0–50 — нетронутые проходят проверку, изменённые отклоняются (ожидается 1000/1000 в обоих случаях).

## Меню

1. ключи RSA: случайные (p, q ∈ [2¹⁷, 2¹⁸)) или вручную p, q, d с проверками (простота, p ≠ q, p·q > 2³², НОД(d, φ) = 1);
2. сообщение: с клавиатуры или случайное из печатных ASCII;
3. подписать: выводятся h (hex и десятичное), S и передаваемая пара (M, S);
4. проверить: текущую пару, изменённое сообщение с той же S или введённые M и S;
5. изменить подписанное сообщение и сразу проверить;
6. автотест на 1000 сообщений;
7. демонстрация условия h < n на ключах n = 33;
0. выход (также Ctrl+C / Ctrl+D).

## Результаты (вариант sin)

- нетронутые сообщения: 1000/1000 проверок пройдено; изменённые: 1000/1000 отклонено;
- при замене одного символа хэш-суммы h' и h'' различаются в среднем на 16 бит из 32 (лавинный эффект хэша ЛР3);
- ключи n = 33: h = 3264597241 ≥ n, S^e mod n = h mod n = 4 ≠ h — проверка нетронутого сообщения не сходится.
