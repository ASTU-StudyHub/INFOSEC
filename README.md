В папке каждой работы: программа, `README.md` с описанием и результатами, отчёт в форматах `.docx` и `.pdf` (для работы 3 отчёт готовится).

## Запуск

```bash
python3 lab1/dh.py
python3 lab2/rsa.py
python3 lab3/myhash.py sin      # вариант: sin, cos или xor
python3 lab4/signature.py       # использует lab2/rsa.py и lab3/myhash.py, запускать из корня
```

Каждая программа работает в консоли через меню; все режимы, требуемые заданием, доступны из меню. Нужен Python 3.8 или новее, сторонние пакеты не используются.
