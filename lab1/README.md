# Лабораторная работа №1 — Протокол Диффи-Хеллмана

Программа моделирует выработку общего сеансового ключа двумя участниками (Алиса и Боб) по открытому каналу. Файлы: `dh.py` — программа, `report.docx` / `report.pdf` — отчёт.

## Запуск

```bash
python3 dh.py
```

## Режимы меню

1. **Случайная генерация параметров.** Алиса (инициатор) выбирает простое p из [5, 9999], порождающий элемент α группы Z*ₚ и секретный показатель x, передаёт Бобу p, α и A = αˣ mod p; Боб выбирает y и отвечает B = αʸ mod p. Обе стороны вычисляют K и программа показывает их совпадение.
2. **Ручной ввод параметров** p, α, x, y с проверками: p — простое из [5, 9999], α — порождающий элемент (порядок равен p − 1), x, y ≥ 1. При неверном значении выводится сообщение и запрос повторяется.
3. **Самопроверка** по таблице 1.1 методических указаний: все 10 строк прогоняются автоматически, для каждой печатается PASS/FAIL.
4. **Перебор ключа третьим лицом** по журналу открытого канала последнего сеанса: по p, α, A секретный показатель находится перебором степеней α, после чего восстанавливается K.
0. Выход (также Ctrl+C / Ctrl+D).

## Особенности реализации

- Открытый канал моделируется классом `Channel`: всё, что передаётся между участниками, печатается в виде «Alice -> Bob: … = …» и записывается в журнал. Секретные показатели и ключ через канал не проходят; режим 4 использует только журнал канала.
- Ограничение задания «< 10000» отнесено к модулю p, поэтому все передаваемые значения и ключ K тоже меньше 10000.
- α выбирается только среди порождающих элементов: случайный кандидат проверяется вычислением порядка элемента (`element_order`). Случайное α без проверки оказывается порождающим лишь примерно в трети случаев.
- Верхняя граница для x и y не проверяется: по малой теореме Ферма αˣ ≡ α^(x mod (p−1)) (mod p), и в таблице 1.1 шесть строк из десяти содержат x или y ≥ p − 1.
- Возведение в степень по модулю выполняет собственная функция `modpow` (бинарный метод, остаток после каждого умножения); она эквивалентна встроенной `pow(a, x, p)`.

## Результаты

- Самопроверка: 10 из 10 строк таблицы 1.1 совпали.
- В случайном режиме во всех сеансах K_A = K_B, сгенерированные p — простые и меньше 10000, α — порождающие.
- Некорректный ручной ввод (составное p, непорождающее α, x = 0, нечисловой ввод) отклоняется с повторным запросом.
- При p < 10000 секретный показатель восстанавливается перебором за доли миллисекунды: учебное ограничение стойкости не даёт; перебор находит x mod (p − 1), чего достаточно для восстановления K.
